# Design implementation checklist

Use this checklist before reporting completion.

## Captured from Sketch

- [ ] Target layer, frame, artboard, or component was identified.
- [ ] Structured hierarchy was inspected with Sketch MCP.
- [ ] Visual reference image was captured from the same target.
- [ ] Required icons, images, or symbol assets were exported from Sketch.
- [ ] Relevant colors, typography, spacing, radius, and effects were recorded.

## Mapped to the codebase

- [ ] Existing components were reused where appropriate.
- [ ] Project tokens were used where they map cleanly to Sketch values.
- [ ] Component boundaries remain maintainable.
- [ ] Responsive behavior follows design constraints.
- [ ] Accessibility basics were preserved.

## Validated

- [ ] Layout and spacing match the captured image.
- [ ] Typography matches the captured image and structured values.
- [ ] Colors, borders, fills, shadows, opacity, and radius are checked.
- [ ] Exported assets render at the intended size and density.
- [ ] Known deviations are explicitly documented.
